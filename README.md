# Tellraw Logger

A simple mod for 1.21.8+ that logs `/tellraw` messages to the console. It overwrites the `TellRawCommand.register` static method, so it may conflict with other mods that also change `/tellraw`. Download in the releases tab or at [Modrinth](https://modrinth.com/mod/tellraw-logger).

Created for use with [Amethyst](https://www.amethyst.dev).

Backporting is trivial if there's demand.
